THE MODEL CHOICE, MEASURED

I didn't default to the biggest model. I tested both.

Five fixed intent classes over WhatsApp-length text is a classification problem, not a generation problem. TF-IDF with logistic regression won on the benchmark, runs in milliseconds, costs fractions of a cent per message, and carries no API dependency at 10,000+ messages a month.

The fine-tuned Gemma-3-1B scored lower, ran slower and cost more. So the lightweight model isn't a compromise — it's the one that won.
